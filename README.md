# QUEIMADAS

`CURSO: Sistemas de Informação`

`DISCIPLINA: Trabalho Interdisciplinar Aplicações para Sustentabilidade`

`1º semestre/2026`

O Queimadas é uma plataforma web desenvolvida com o objetivo de auxiliar no monitoramento, prevenção e denúncia de focos de queimadas. O sistema disponibiliza um mapa interativo que permite visualizar ocorrências registradas e adicionar novas, facilitando o acompanhamento das áreas afetadas e contribuindo para a conscientização ambiental da população.

Além da visualização geográfica dos focos de incêndio, a aplicação permite o cadastro e gerenciamento de denúncias, fornecendo uma ferramenta acessível para que cidadãos possam reportar ocorrências de forma rápida e organizada. Dessa forma, o projeto busca apoiar ações de fiscalização, promover a participação da sociedade e contribuir para a preservação do meio ambiente.

## Instruções de utilização

### Acesso à aplicação

A aplicação está disponível em:

https://disquequeimadas.vercel.app/

### Como utilizar

1. Acesse o sistema pelo link disponibilizado.
2. Visualize o mapa interativo com os focos de queimadas e denúncias registradas.
3. Navegue pelas informações disponíveis para acompanhar ocorrências ambientais.
4. Utilize as funcionalidades de cadastro e consulta de denúncias quando necessário.
5. Acompanhe os dados apresentados pelo sistema para obter informações sobre as áreas monitoradas.
