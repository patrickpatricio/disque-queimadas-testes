# Avaliação

Os resultados demonstraram que os usuários conseguiram concluir todas as tarefas propostas com sucesso, indicando que a plataforma apresenta boa usabilidade e atende aos objetivos definidos para o projeto.

As funcionalidades mais bem avaliadas foram a visualização do mapa de calor e a consulta das regiões afetadas, permitindo aos participantes compreender rapidamente a situação das queimadas na cidade.

As principais dificuldades identificadas estiveram relacionadas à localização do controle de camadas geográficas e ao preenchimento do formulário de denúncia, principalmente para usuários com menor experiência em sistemas de mapas.

Com base nos comentários recebidos, foram identificadas as seguintes oportunidades de melhoria:

- Destacar melhor o seletor de camadas geográficas;
- Adicionar instruções mais claras no formulário de denúncia;
- Melhorar a experiência de navegação em dispositivos móveis;
- Inserir orientações rápidas para novos usuários.

De forma geral, os testes demonstraram que a solução atende aos requisitos de usabilidade definidos para o projeto, apresentando uma experiência satisfatória para os usuários e potencial para futuras melhorias.
