# Template Padrão da Aplicação

O sistema **Disque Denúncia Queimadas e Irregularidades** utiliza um template visual simples, moderno e responsivo, desenvolvido para facilitar o monitoramento ambiental e o registro de denúncias pela população de Betim – MG.

A aplicação foi construída no modelo **Single Page Application (SPA)**, permitindo atualização dinâmica das informações sem recarregar a página. O mapa interativo é o principal elemento da interface, acompanhado por gráficos, indicadores e painel de denúncias.

---

# Identidade Visual

A identidade visual do sistema foi desenvolvida com foco em sustentabilidade, monitoramento ambiental e alertas de risco.

As principais cores utilizadas representam os níveis de criticidade das ocorrências:

| Cor | Significado |
|---|---|
| Verde | Baixa incidência |
| Laranja | Atenção |
| Vermelho | Área crítica |

Além disso, a aplicação utiliza cores neutras para organização visual e elementos de navegação.

---

# Tipografia e Responsividade

O sistema utiliza fontes simples e legíveis, priorizando acessibilidade e boa visualização em computadores e dispositivos móveis.

A plataforma pode ser acessada por:

- Computadores;
- Tablets;
- Smartphones.

---

# Estrutura do Layout

A interface principal da aplicação reúne:

- Mapa interativo;
- Controle de camadas;
- Dashboard analítico;
- Gráficos estatísticos;
- Painel de denúncias.

Grande parte das funcionalidades do sistema está centralizada em uma única tela principal.

---

# Logo e Elementos Visuais

Os elementos gráficos da plataforma representam conceitos relacionados a queimadas, meio ambiente, localização geográfica e monitoramento ambiental.

Os ícones auxiliam na navegação e identificação rápida das funcionalidades do sistema.
